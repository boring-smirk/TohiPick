# TohiPick

Single-file web app for ordering university choice codes with drag-and-drop.

## Quick Start (EN)

1. Open `R∅shte_T_Vr.html` on GitHub and download **Raw** (or clone the repo).
2. Open the file in any modern browser.

## Core Features

- Drag to reorder priorities (`⠿`)
- Multi-select and batch move/delete
- Search by code/university/major/description
- Export codes, full list, CSV, or reordered HTML
- Reset to initial data
