# TohiPick

TohiPick is a lightweight, single-file web app for ordering and managing university choice codes (drag-and-drop ranking).

## Project Structure

- Main app: `/R∅shte_T_Vr.html`
- No build step, backend, or installation required.

## Quick Start (English)

### Option A: Use from GitHub UI (recommended for non-technical users)
1. Open this repository on GitHub.
2. Click the file **`R∅shte_T_Vr.html`**.
3. Click **Download raw file** (or **Raw** then save the page as `.html`).
4. Open the downloaded file in your browser (Chrome/Edge/Firefox).

### Option B: Use locally after clone
1. Clone/download the repository.
2. Open `R∅shte_T_Vr.html` directly in your browser.

## How to Use

- Reorder items by dragging the `⠿` handle.
- Select one or multiple rows for batch move/delete.
- Search by code, university, major, or description.
- Add items one-by-one or in bulk.
- Export:
  - `📋` copy only codes
  - `📄` copy full ordered list
  - `📥` CSV export
  - `💾` export a new HTML file with your current order
- Reset to initial data with `↺`.

## Data Persistence

- Your edits/order are saved in browser `localStorage`.
- Data stays on your device unless you export/share files manually.

## شروع سریع (فارسی)

TohiPick یک ابزار سبک و تک‌فایلی برای مرتب‌سازی انتخاب رشته است (با جابه‌جایی Drag & Drop).

### ساختار پروژه

- فایل اصلی برنامه: `/R∅shte_T_Vr.html`
- نیازی به نصب، بک‌اند یا Build ندارد.

### اجرای برنامه از داخل GitHub (مناسب کاربران عمومی)
1. وارد مخزن شوید.
2. روی فایل **`R∅shte_T_Vr.html`** کلیک کنید.
3. روی **Download raw file** (یا **Raw**) بزنید و فایل را با پسوند `.html` ذخیره کنید.
4. فایل ذخیره‌شده را در مرورگر باز کنید.

### اجرای محلی
1. مخزن را دانلود/کلون کنید.
2. فایل `R∅shte_T_Vr.html` را مستقیم در مرورگر باز کنید.

### روش استفاده

- جابه‌جایی اولویت‌ها با گرفتن دسته `⠿`.
- انتخاب چند مورد و جابه‌جایی/حذف گروهی.
- جستجو بر اساس کد، دانشگاه، رشته یا توضیحات.
- افزودن کدها به‌صورت تکی یا دسته‌ای.
- خروجی‌ها:
  - `📋` کپی کدها
  - `📄` کپی لیست کامل
  - `📥` خروجی CSV
  - `💾` خروجی HTML با ترتیب فعلی
- بازنشانی کامل با `↺`.

### نگهداری داده

- تغییرات و ترتیب‌ها در `localStorage` مرورگر ذخیره می‌شوند.
- اطلاعات فقط روی دستگاه شما می‌ماند مگر اینکه فایل خروجی را خودتان به اشتراک بگذارید.
